# YES 모집·신청

남가주 사랑의교회 모집 광고를 한곳에 모으는 앱입니다.

- `/` 모집 게시판 (주보에는 이 주소나 QR 하나만 넣으면 됩니다)
- `/r/<광고>` 광고 상세 · 앱 신청서
- `/go/<광고>` 부서 신청 링크로 넘어가기 (클릭 수를 셉니다)
- `/admin` 관리자: 신청 현황 · 광고 관리 · 주보에서 가져오기
- `/m/<광고>?k=…` 부서 담당자 링크 (그 모집의 신청만 봅니다)

처음 열 때 2026년 11월 셋째 주 주보의 모집 광고 10개가 들어가 있습니다. 연말 특새 섬김은 숨김 상태입니다.
환경 변수는 `.env.example`을 보세요. 데이터 키는 `recruit:`로 시작하므로 다른 YES 앱과 같은 Upstash 데이터베이스를 써도 됩니다.
